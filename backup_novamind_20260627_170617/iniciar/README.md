# NovaMind

## Como rodar (1 comando)

```
iniciar\_grounding.bat
```

Isso inicia:
- **Backend** (porta 8000) — AGI aprendendo sozinha
- **Frontend** (porta 5173) — Interface pra ver o que ela ta vendo

Pronto. So isso.

## Modo alternativo: Sala de Aula

5 mentes conversando entre si:

```
iniciar\_colonia.bat
```

Cada mente busca fontes diferentes (YouTube, Wikipedia, SciELO)
e discutem o que aprenderam.

## O que tem no sistema

- **Memoria com relevancia adaptativa** — Ebbinghaus, valencia emocional, replay
- **Predictive coding** — prediz o proximo input, erro vira atencao
- **Neuronios espelho** — observa acao, tenta reproduzir
- **Playground** — ambiente simulado onde a AGI age e ve consequencias
- **Plasticidade estrutural** — poda conexoes fracas, fortalece fortes
- **Regulacao homeostatica** — mantem firing rate estavel
- **Active inference** — escolhe a proxima acao por menor surpresa
- **Whisper uncertainty** — transcreve com confianca, pondera input

## Nao acumula lixo

Videos sao baixados, processados frame-a-frame com display live,
e apagados automaticamente. `iniciar\_limpar_temp.bat` pra limpeza manual.
