# Estado perceptivo como hipóteses concorrentes

O rastreador guloso da suíte física cria uma única identidade para cada corpo.
Quando dois se fundem ou somem atrás do oclusor, uma atribuição errada pode
persistir. Este ensaio exploratório guarda até 16 atribuições alternativas.
Cada hipótese é executável: posições, velocidades, última observação e custo
acumulado. A próxima imagem elimina ou reordena hipóteses pelo erro de
previsão; os alvos futuros e a verdade do simulador não entram na filtragem.

O extrator deve produzir tanto a hipótese mais provável quanto uma média com
incerteza das hipóteses. Comparar com pixels e rastreador guloso nos mesmos
mundos, e com identidades embaralhadas. A medida principal continua sendo
arrependimento de decisão reservado por mundo, não erro geométrico. Este método
usa até três entidades nesta bancada e não resolve ontologia geral. Os mundos
53/97/101/107/113 já foram observados: qualquer análise neles é exploratória.
Uma confirmação requer sementes nunca usadas depois de congelar o código.
